## 1. Field definitions

| Field | How to record it | Allowed values |
|---|---|---|
| **Task ID** | The task number | T1 … T8 |
| **Task description** | Short label (do not re-type the full script) | Find product · Filter · Product detail · Select variant & add · Change quantity · Contact & address · Payment method · Place order |
| **Outcome** | The single most important judgement | `Success` · `Partial` · `Failed` |
| **Completion time** | Seconds from the end of the task prompt to the success condition (or to the stop) | integer, seconds |
| **Errors** | Count of incorrect actions, counted once per distinct mistake | integer |
| **Assistance required** | Highest level of the assistance ladder that was used | `None` · `Prompt` · `Hint` · `Instruction` · `Assist` |
| **Participant comments** | Verbatim where possible. Quote rather than paraphrase | free text |
| **Observer notes** | Your interpretation: what this tells you about the design | free text |

### Outcome rules
- **Success** — the task's success condition was met, with **no assistance beyond level 1**.
- **Partial** — the task was reached but not completed cleanly, **or** it was completed only with assistance at level 2 or above, **or** the participant completed it without understanding what they had done.
- **Failed** — the task could not be completed, or was abandoned.

### Error definition — what counts and what does not
| Counts as an error | Does **not** count as an error |
|---|---|
| Clicking a control that does nothing | Typing slowly or correcting a typo |
| Entering a value the form rejects (e.g. a phone with the country code in it) | Reading the screen before acting |
| Navigating to the wrong page and coming back | Asking "where is it?" |
| Failing to notice a required field | Using the search box instead of browsing |
| Re-entering a field already filled | Pausing to read |
| Choosing the wrong variant and changing it | Backtracking to read something |

> Count each **distinct** mistake once, even if repeated. "Clicked Remove twice" is one error, not two.

### Quick reference — assistance ladder
`None` → `Prompt` (re-read the task) → `Hint` (point at the region) → `Instruction` (name the control) → `Assist` (do it for them)

> **A Success with assistance at level 2 or above is recorded as Partial.**
